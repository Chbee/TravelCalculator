# Make Prompt For App Icon

This file contains a Make-friendly prompt for generating app icon variations.

## Recommended Make Inputs

- Number of images: `4`
- Size: `1024x1024`
- Aspect ratio: `1:1`
- Background: `opaque`
- Output format: `PNG`
- Output delivery: `4 separate downloadable PNG files`

## Prompt

```text
Create exactly 4 refined iOS app icon variations for a travel currency calculator, based on one consistent design direction.

Base direction:
- Use Concept 1 as the main composition and meaning
- Keep the calculator as the dominant central object
- Keep a clear exchange display inside the calculator screen so the icon immediately communicates currency conversion
- Remove the small circular pin-like ornament attached near the upper-right side of the calculator
- Do not add any floating side ornament in that area

Keypad direction:
- Use the cleaner keypad style of Concept 4
- Simplify the calculator buttons into fewer, bolder, more readable shapes
- Improve spacing and clarity so the keypad remains legible at small icon sizes

Variation goal:
- Generate 4 different concepts within this same base direction
- Each of the 4 images should explore a slightly different visual interpretation, such as display layout, exchange arrow treatment, button arrangement, contrast balance, depth, or silhouette refinement
- Keep all 4 images clearly related, but visually distinct enough to compare as separate concepts

Design goal:
- The icon must instantly communicate travel spending calculation and currency conversion
- The calculator must remain the primary subject
- The exchange meaning must be obvious at a glance
- Any travel cue must be extremely subtle or omitted if it weakens clarity

Visual style:
- Premium Apple-style iOS app icon
- Minimal but distinctive
- Strong central silhouette
- High contrast
- Clean geometric shapes
- Polished lighting and subtle depth
- Refined blue-gray and airy cool-tone color palette
- Crisp edges and excellent legibility at small sizes

Output requirements:
- Create exactly 4 images
- 1024x1024 pixels each
- Square 1:1 composition
- Opaque background
- PNG output
- Deliver each image as an individual downloadable PNG file

Avoid:
- Airplane as the main subject
- Suitcase as the main subject
- Globe or map as the main subject
- Generic banking or fintech logo look
- Too many symbols or decorative elements
- Tiny keypad details
- Text, letters, or labels
- Photorealistic rendering
- Busy or cluttered composition
- Purple-heavy gradients

The final images should feel modern, trustworthy, travel-oriented, and immediately recognizable on an iPhone home screen.
```

## Short Version

```text
Create exactly 4 refined iOS app icon variations for a travel currency calculator. Use Concept 1 as the base direction, but remove the small circular ornament near the upper-right side of the calculator. Keep the calculator as the dominant central object and show clear currency conversion inside the display. Use the cleaner keypad style from Concept 4, with fewer and bolder buttons for better readability. Generate 4 related but distinct concepts within this same direction. Premium Apple-style icon, minimal but distinctive, strong silhouette, blue-gray cool-tone palette, polished depth, high contrast, 1024x1024, square 1:1, opaque background, and deliver each result as an individual downloadable PNG file. Avoid airplanes, suitcases, globes, maps, generic banking style, text, photorealism, clutter, tiny keypad details, and purple-heavy gradients.
```
